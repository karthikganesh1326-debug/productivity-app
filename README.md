# 🧠 Productivity Dashboard (React + Vite)

A clean and simple productivity dashboard built using React and Vite.

## 🚀 Features

- 📅 Date Picker (Calendar)
- 📝 Notes Section
- ✅ To-Do List (Add & Delete Tasks)
- 🔙 Back to Home Navigation
- 🎨 Clean and Professional UI
- ⚡ Fast build with Vite

## 🛠️ Tech Stack

- React
- Vite
- JavaScript
- CSS
- React Router DOM
